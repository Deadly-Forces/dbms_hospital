# Hospital Management System

This project is a simple web application for managing patient details in a hospital. It allows users to add patient information, view patient details, and generate various reports.

## Project Structure

```
hospital-management-system
├── static
│   ├── css
│   │   └── style.css
│   └── js
│       └── script.js
├── templates
│   ├── base.html
│   ├── index.html
│   ├── add_patient.html
│   ├── patient_details.html
│   └── reports.html
├── app.py
├── database.py
├── requirements.txt
└── README.md
```

## Features

- Add new patient details (age, name, blood group, type of disease).
- View patient details.
- Generate reports based on stored patient data.

## Technologies Used

- Python
- Flask
- HTML/CSS
- JavaScript

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd hospital-management-system
   ```

3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

4. Run the application:
   ```
   python app.py
   ```

5. Open your web browser and go to `http://127.0.0.1:5000` to access the application.

## Usage

- Use the main page to navigate to different sections of the application.
- Fill out the form to add a new patient.
- View patient details and generate reports as needed.
